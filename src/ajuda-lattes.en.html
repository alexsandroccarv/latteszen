How to use lattesZen

A guide to the procedures for organizing, backing your Lattes Curriculum with evidence, and publishing it. The RSC-PCCTAE module has its own help page.

In one sentence: you pick a folder on your computer → import your Lattes XML (or enter items manually) → attach supporting PDFs → track what's missing in the Compliance tab → and can publish everything as a public CV page.

Workflow overview

lattesZen runs entirely in your browser — no data ever leaves your computer. CV items are saved to a folder you choose, each one as a pair of files: the ID.json (the data) and, when there is one, the ID.pdf (the supporting evidence).

The typical workflow is:

  1. Set up the folder where everything will be saved (just once).
  2. Import the XML exported from the Lattes Platform — it brings in your items automatically.
  3. Attach supporting evidence (PDFs) to each item, using the inbox folder.
  4. Check the Compliance tab for what's still missing (evidence or fields).
  5. Publish whenever you're ready: generate the public CV page from the same data.
Browser: saving to a folder uses the File System Access API, available in Google Chrome and Microsoft Edge (desktop). In unsupported browsers, you can still enter items and use JSON backup, but not automatic PDF/JSON saving to the folder.

1 Create and choose the file directory

First, create an empty folder on your computer for your CV (for example My-Lattes). Then, in lattesZen:

  1. Open the Settings tab.
  2. Under Storage directory, choose First-time setup → Folder on my computer and click 📁 Choose folder.
  3. Select the folder you created and grant access when the browser asks.

Done — from then on, every item you save is written there automatically. The current folder's name appears in this same section.

Alternative: Google Drive

If you'd rather not depend on a single computer, the same Settings section has Remote storage (Google Drive): enter a folder name and click Connect to Google Drive. lattesZen creates the same folder structure inside your Drive and reads/writes there instead — accessible from more than one device. Access is restricted to the drive.file scope: the app can only see files it creates itself, never the rest of your Google Drive.

What gets saved to the folder

  • For each item: prefix-XXX.json (the data) and, if you attach evidence, prefix-XXX.pdf (or .jpg/.png, among others).
  • Files are organized into subfolders by category inside Evidências (e.g. 02 Formação, 05 Produções, 10 Orientações…), which keeps everything browsable outside the app too.
  • A Cópia de segurança subfolder holds automatic JSON copies of the catalog.
  • Inside Exportação, three subfolders are filled in automatically by the app itself: RSC-PCCTAE and Súmula Curricular FAPESP (a dated subfolder per export, holding the memorial/form or the summary as .docx — see the RSC guide and the Súmula FAPESP tab in Settings) and Lattes XML (the XML generated under Settings). Progressão Docentes, Publicação para Web, and Relatórios stay empty, for you to organize your own files manually.
My-Lattes/ ├── Caixa de Entrada/ ← drop the PDFs you're about to catalog here │ └── Processados/ ← originals already used are moved here ├── Cópia de segurança/ ← automatic backups (JSON) ├── Exportação/ │ ├── RSC-PCCTAE/ │ ├── Progressão Docentes/ │ ├── Súmula Curricular FAPESP/ │ └── Lattes XML/ ├── Evidências/ │ ├── 01 Dados gerais/ │ ├── 02 Formação/ │ ├── 05 Produções/ │ │ ├── lz-a3f.json │ │ └── lz-a3f.pdf │ └── … (one subfolder per category, 01–21) ├── Publicação para Web/ └── Relatórios/

Identifier prefix

Under Settings → File identifier prefix you set up to 3 characters (e.g. your initials) used in file names: abc-k7p.pdf. Useful if you keep more than one person's CV in different folders.

Useful buttons in this section

  • Sync from directory: re-reads the folder and rebuilds the catalog from the files (e.g. after switching computers or opening the same folder on another day).
  • Forget storage directory: disconnects the app from the folder (doesn't delete anything; just removes the link).
Tip: since your data lives in the folder, you can back it up (cloud, external drive) or move it to another computer and simply Choose folder again there.

2 The inbox folder — Caixa de Entrada

The Caixa de Entrada folder is your inbox: the place where you drop supporting PDFs before cataloging them. It's created automatically inside the directory.

How to use it

  1. Copy every supporting document you plan to attach into Caixa de Entrada (certificates, letters, first pages of articles, committee minutes…).
  2. On the Catalog tab, the inbox shows the pending files. Click the inbox icon to load the next file as evidence for the item you're filling in.
  3. When you save the item, the original file is moved to Caixa de Entrada/Processados — so the inbox always shows only what's still left to catalog.
Why it exists: it separates "what I still need to organize" from "what's already cataloged," avoiding attaching the same document twice. You can also attach evidence by dragging a file straight onto the form, without going through the inbox.

3 Import the Lattes Curriculum XML

Instead of typing everything in, import what already exists in your Lattes record:

a) Export the XML from the Lattes Platform

  1. Access your CV on the CNPq / Lattes Platform website.
  2. From the menu, choose Export → XML and download the .zip file; it contains curriculo.xml (unzip it).

b) Import into lattesZen

  1. Open Settings → Import Lattes Curriculum (XML) section.
  2. Select the curriculo.xml file.
  3. The app lists every recognized item, grouped by type, showing how many are new and how many are already cataloged.
  4. Check the ones you want to bring in (there are Select new / All / None shortcuts) and click Import selected.
No duplicates: on every import, lattesZen recognizes items that already exist (by content signature) and doesn't duplicate them — even ones you edited or created manually. They show up as "already cataloged," unchecked by default. After importing, just attach each one's PDFs.
To stay consistent: once you adopt lattesZen, make edits here in lattesZen rather than directly on the Lattes Platform — lattesZen becomes your reference source for future import cycles. Editing an item directly on the Lattes Platform changes its identifier and can cause duplication on the next import.
Accented characters: Lattes uses ISO-8859-1 encoding. lattesZen correctly decodes imported files, preserving accents and special characters.

4 Other sources: ORCID, DOI, and BibTeX/RIS

Besides the Lattes XML, the Other sources section in Settings offers three more ways to bring in publications without typing everything by hand:

a) ORCID iD

Under Settings → Import from ORCID, enter your ORCID iD (format 0000-0000-0000-0000) and click Search. The app queries the public ORCID API (no login) and lists your public works for you to choose which to import — same selection and duplicate-detection pattern as the XML import.

b) DOI (Crossref)

When manually entering a bibliographic production item (article, chapter, conference paper…) under the Catalog tab, fill in the DOI field and click Fetch metadata next to it: lattesZen queries the public Crossref API and automatically fills in the form's empty fields (title, authors, year, journal…). If a field is already filled in, the app asks before overwriting it.

c) BibTeX / RIS

Under Settings → Publications (BibTeX/RIS), import a .bib or .ris file exported from another tool (Zotero, Mendeley, EndNote, Google Scholar) — the app recognizes the format automatically, lists the mapped entries (and flags ones with no match) and you choose which to import. The same section also exports your already-cataloged publications to .bib or .ris, in case you need to take them to another tool.

5 Filling in fields (Catalog tab)

The Catalog tab is where you create or edit an item. The form adapts to what you select:

  1. Category: choose from the Lattes categories (General Data, Education, Productions, Patents and Registrations, Events, Advising, Committees…).
  2. Type: within the category, choose the specific type (e.g. under Productions → Full article published in a journal). There's a search field to find the type quickly.
  3. Fields: the form shows only the fields for that type (title, year, authors, ISSN, DOI, country, language, etc.). Required fields are flagged.
  4. Evidence (PDF): drag the supporting file onto the indicated area, use the file picker, or pull it from the inbox with "Next from inbox". You can mark a piece of evidence as "public" — only public ones appear on the public CV page.
  5. Save: writes the JSON (and the PDF, if any) to the category's subfolder.

Details that help

  • Identity fields (Identification, Address, Opening text, Profile photo, among others under "1. General Data") are unique — saving updates the existing record instead of creating another. Entered/edited through the same Catalog flow as any other item.
  • Autocomplete: fields like Institution and Agency suggest values you've already used. The lists can be edited under Settings → Autocomplete lists.
  • Duplicate detection: when you create an item very similar to an existing one, the app warns you before saving.
  • Draft: what you're typing is preserved; if you leave without saving, the app offers to restore the draft.

6 Keyboard shortcuts

On the Catalog tab, a few shortcuts speed up data entry without leaving the keyboard:

ShortcutAction
Ctrl+S Cmd+S on MacSaves the item being edited — same as the Save button.
Ctrl+Enter Cmd+Enter on MacSaves and moves on: opens the next item in the Compliance list (same filter/search/sort as there) if you're editing an existing item, or, when creating a new item, saves and clears the form for a new item in the same category/type — same as the Save and next/Save and new buttons.
Alt+↓ / Alt+↑While editing an existing item, navigates to the next/previous item in the same Compliance list without saving. If there are unsaved changes in the form, the app confirms before discarding them.
Tip: the form buttons also show their matching shortcut on hover (title/tooltip).

7 The Compliance tab

The Compliance tab is your control panel: it shows, at a glance, what's complete and what's still missing. It works with two independent dimensions:

DimensionWhat it measures
Documentary compliancePercentage of items that require supporting evidence and already have one (a PDF) attached.
Complete descriptionPercentage of items with every field filled in — green = complete, yellow = missing an optional field, red = missing a required field.

The cards (quick filters)

At the top, clickable cards filter the list below:

  • With evidence — items with attached supporting evidence.
  • No PDF — items that need evidence and don't have any yet.
  • Not yet on Lattes — items marked as not yet entered on the Lattes Platform.
  • Non-Lattes — personal/administrative items that aren't part of the Lattes record.
  • Required description — items missing a required field.

Click a card to see just that slice; click "view all" to clear the filter. There's also text search and sorting by year.

The list

Below the cards, items appear grouped by category (and, under Professional Activity, by institution). Each item has action buttons (edit, view evidence, delete) and status markers. Use this tab as a checklist until nothing's left pending.

8 The Charts tab

The Charts tab offers two quick views of your catalog:

Word cloud

Shows the most frequent terms across your items' titles, keywords, and field of knowledge — the bigger the word, the more often it appears. Hover over a word to see the exact count.

Under Settings → Word cloud you can customize the result with two lists: excluded words (terms that should never appear, e.g. a generic acronym) and compound words (multi-word terms that should count as a single term, e.g. "tech talks" instead of "tech" and "talks" separately).

Timeline (heat map)

A panel in the style of a "contribution graph": each row is a category in your catalog (only the ones with at least one item), each column is a year, and the color of each square gets stronger the more items of that category fall in that year. Hover over a square to see the exact count.

Each item's year uses the same criterion already used for sorting by year in Compliance: the item's Year field or, failing that, the end (or start) of its period — a single year per item, even for ones with a start and end (e.g. Education, Professional Activity). Both views ignore the General Data category — that's identification/profile data, not "output."

9 Publish the public page

Under the Publish on the Web tab you generate the public CV page — a single, self-contained HTML file, with evidence marked as "public" embedded. It can be hosted or shared.

Backup and encoding

JSON backup

Under Settings → Backup (JSON) you export/import the whole catalog (the metadata) as a single file. With a directory set up, a backup is also saved automatically to Cópia de segurança. Keep it up to date — the app reminds you periodically.

ISO-8859-1 compatibility

Still under Settings, the Lattes compatibility section flags characters outside the ISO-8859-1 table (curly quotes, em dashes —, emoji…) that would turn into numeric entities on export, and offers Normalize punctuation to clean up the text.
