# Países (Plataforma Lattes)

Lista de países extraída da tela do Currículo Lattes (campo **País**), com
o código interno de 3 letras usado pelo Lattes e o nome em português.
Referência para o campo **País** do lattesZen (Instituição de execução,
Instituições envolvidas, Instituição de financiamento — categoria Projetos —
e demais campos de país da aplicação).

Os 13 primeiros (Alemanha…Portugal) aparecem destacados no topo da lista
real do Lattes; os demais seguem a ordem original da tela. Um código
duplicado (`RTC` para "República Tcheca", já coberto por `TCH`) foi omitido
da lista usada pela aplicação, mas fica registrado aqui para fidelidade à
fonte.
