# Mapeamento do Currículo Lattes

> Mapeamento estrutural (somente estrutura de campos, sem conteúdo preenchido) do sistema de edição do Currículo Lattes (CNPq).

## 1. Dados gerais

### 1.1 Identificação

1.1.1 Foto de perfil (upload) — com controle de visibilidade (lista suspensa: Público/Privado)

1.1.2 Nome completo (texto)

1.1.3 Deseja utilizar o nome social? (radio) — opções: Não, Sim

1.1.4 Nome em citações bibliográficas (grupo repetível — lista de nomes adicionados via campo de texto + tecla Enter)

1.1.5 País de Nacionalidade (lista suspensa) — com visibilidade (lista suspensa: Público/Privado)

1.1.6 CPF (texto, bloqueado para edição) — com visibilidade (lista suspensa: Público/Privado)

1.1.7 Cor ou raça (lista suspensa) — com visibilidade (lista suspensa: Público/Privado)

1.1.8 Dados do nascimento: País (lista suspensa), UF (lista suspensa), Cidade (texto), Data (data) — com visibilidade (lista suspensa: Público/Privado)

1.1.9 Identidade: Número (texto), Órgão emissor (texto), Unidade Federativa (lista suspensa), Data de emissão (data) — com visibilidade (lista suspensa: Público/Privado)

1.1.10 Passaporte: Número do passaporte (texto), Data de validade (data), Data de emissão (data), País de emissão (lista suspensa) — com visibilidade (lista suspensa: Público/Privado)

1.1.11 Você é uma pessoa com Deficiência? (radio) — opções: Não, Sim

1.1.12 Outros identificadores — ORCID iD: link "Register or Connect your ORCID iD" (outro tipo — vínculo/autenticação externa) e tabela somente leitura com Base/Endereço (URL) já vinculado

### 1.2 Endereço

1.2.1 Residencial — País (lista suspensa), CEP (texto, com link "Não sei meu CEP"), Logradouro (texto), Bairro (texto), Cidade (texto), Estado/província (texto), DDD (texto), Telefone (texto), Ramal (texto), Fax (texto), Caixa postal (texto), DDD celular (texto), Celular (texto), Home page (texto), Utilizar este endereço para correspondência (radio), Visibilidade (lista suspensa: Público/Privado)

1.2.2 Profissional — Instituição/Empresa (texto com busca), Órgão/Unidade (texto com busca), País (lista suspensa), CEP (texto, com link "Não sei meu CEP"), Logradouro e complemento (texto), Bairro (texto), Cidade (texto), Estado/província (texto), DDD (texto), Telefone (texto), Ramal (texto), Fax (texto), Caixa postal (texto), DDD celular (texto), Celular (texto), Home page (texto), Utilizar este endereço para correspondência (radio), Visibilidade (lista suspensa: Público/Privado)

1.2.3 Eletrônico — e-mail para contato (texto) com visibilidade (lista suspensa), e-mail alternativo (texto) com visibilidade (lista suspensa)

1.2.4 Outra forma de contato (grupo repetível) — Contato (lista suspensa, ex.: Google Talk), Endereço (texto), Visibilidade (lista suspensa: Público/Privado)

1.2.5 Redes Sociais (grupo repetível) — Rede Social (lista suspensa, ex.: Facebook), Endereço da Rede (texto), Visibilidade (lista suspensa: Público/Privado)

### 1.3 Licença Maternidade, Paternidade e Adoção

1.3.1 Cadastro de Licenças (grupo repetível) — Tipo (lista suspensa: Maternidade, Paternidade, Adoção), Data Início (data), Data Fim (data), Data de nascimento/adoção (data), Período de Licença (campo calculado/exibição), Visibilidade (lista suspensa: Público/Privado)

### 1.4 Idiomas

1.4.1 Proficiência em idiomas (grupo repetível) — Selecione o idioma (lista suspensa); para cada habilidade Lê, Fala, Escreve, Compreende: checkbox de habilitação + radio de nível (Pouco, Razoavelmente, Bem); Visibilidade (lista suspensa: Público/Privado)

### 1.5 Prêmios e títulos

1.5.1 Prêmios e títulos honoríficos recebidos (grupo repetível) — Nome do prêmio ou título (texto), Entidade promotora (texto), Ano da premiação ou do título (texto/numérico), Visibilidade (lista suspensa: Público/Privado)

### 1.6 Texto inicial do Currículo Lattes

1.6.1 Texto inicial (texto longo, limite 4000 caracteres) + botão "Utilizar o Texto Padrão"

1.6.2 Tradução (texto longo, limite 4000 caracteres) + botão "Utilizar o Texto Padrão"

### 1.7 Outras informações relevantes

1.7.1 Outras informações relevantes (texto longo, limite 2000 caracteres)
